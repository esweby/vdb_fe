# Card coverage

This is the rules-checking order for cards found in the same FaBlazing Viserai logs used for the T5 investigation. It covers 57 daily exports from 21 September to 20 October 2026, across formats 0 and 1. After the existing player cap, the logs contain 29,020 detailed Viserai sides. Early abandoned games stay in this deck-list count, but they do not contribute plays or results elsewhere in the FaBlazing reports.

## What the ranking means

A use means that one card variant appeared in one Viserai side's list. It does not count copies or the number of times the card was played. This makes a card used by 20,000 different sides rank above a card repeatedly played by fewer sides.

Each pitch is ranked separately because the engine may have rules for one pitch but not another. **Verified** means that exact card and pitch currently returns rules from `verifiedRulesFor`. It does not mean every combat effect is modelled; it means the maintainer has accepted the rules the engine currently uses.

There were 682,257 card uses across 419 variants. The 85 verified variants account for 373,978 uses, or 54.81% of the observed total. Within the top 100, 35 variants are verified and they account for 55.88% of those variants' uses.

## Check shared patterns once

- Treat all pitches of the same named card as one review unless the numbers or wording change by pitch. The main table still shows each pitch separately so its priority is clear.
- Treat the Gloomblades as one shared check for playing from banish, Usurp and Blood Debt, followed by the exception on each named card. All 16 Gloomblade entries in the top 100 already have verified rules.
- Treat Widespread Annihilation, Widespread Ruin and Widespread Destruction as one cycle. None currently has verified rules.
- Treat the Runechant of Lust, Sloth and Greed cards as one Sinchant pattern check. All three entries in the top 100 already have verified rules.
